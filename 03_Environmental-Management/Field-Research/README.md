# Environmental Management · Field Research

Each exercise gets a write-up made from the [exercise template](../../00_Learning-Plan/templates/exercise-template.md): Frame → Understand → Build with Claude Code → Verify yourself → Reflect.

**Naming:** `YYYY-MM-DD_short-description.md`, e.g. `2026-11-15_monitoring-summary-stats.md`. Put the exercise's code and outputs in a matching subfolder (e.g. `2026-11-15_monitoring-summary-stats/`). Raw data goes in `data/` and stays out of git.
