# Environmental-Experiential-Systems-Design

A self-directed program building a systems design practice across spatial intelligence, systems engineering, environmental management, service design, and data/AI — each track ending in a portfolio project, all converging in an integrated capstone.

```
00_Learning-Plan/              roadmap & progress
01_GIS-Spatial-Intelligence/   Courses · Exercises · Portfolio-Project
02_Systems-Engineering/        Courses · Diagrams · Portfolio-Project
03_Environmental-Management/   Courses · Field-Research · Portfolio-Project
04_Service-Experience-Design/  Courses · Research · Portfolio-Project
05_Data-Software-AI/           Python · SQL · AI-Experiments · Portfolio-Project
06_Integrated-Capstone/
```

## Conventions
- **Folders:** numbered prefix + Title-Case-With-Hyphens; no spaces.
- **Files:** `YYYY-MM-DD_short-description.ext` for dated work.
- **Large data** (rasters, geodatabases, raw datasets, videos) stays local — see `.gitignore`. Put it in a `data/` subfolder and note its source in a README.
